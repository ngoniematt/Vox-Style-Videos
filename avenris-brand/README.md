# Avenris logo kit (v1)

Wordmark concept: **Step Forward**. The E is drawn as three bars, and the middle bar steps forward. Only that bar takes colour.

## Files
| File | Use on |
|---|---|
| `avenris-wordmark-primary.svg` | Light backgrounds (parent brand) |
| `avenris-wordmark-reversed.svg` | Navy or dark backgrounds |
| `avenris-care-lockup-primary.svg` | Avenris Care on light backgrounds |
| `avenris-care-lockup-reversed.svg` | Avenris Care on navy or dark backgrounds |
| `*-black.svg` / `*-white.svg` | Single-colour printing: embroidery, stamps, fax, photos |
| `avenris-icon.svg`, `avenris-care-icon.svg` | App icon, social avatar, favicon |
| `png/` | PNG exports: logos 2000px wide, icons at 512/180/32px |

Use the SVG wherever possible. Use the PNG only where SVG isn't accepted.

## Colours (Midnight & Dawn)
| Name | Hex | Role |
|---|---|---|
| Midnight | `#13203A` | Letters and primary background |
| Paper | `#F4F2EE` | Light background and reversed letters |
| Dawn | `#F2A33A` | Parent bar on dark backgrounds only |
| Dawn Ink | `#B8650C` | Parent bar on light backgrounds |
| Care Sage | `#9BD1A6` | Care bar on dark backgrounds only |
| Care Sage Ink | `#3E8A5A` | Care bar on light backgrounds |

## Rules
- Never line the three bars up evenly. The step is the logo.
- Only the middle bar takes colour. Use one company colour per surface.
- Bright colours (Dawn, Care Sage) only on dark backgrounds. They fail contrast on white.
- Keep clear space around the logo equal to the height of the E.
- Minimum width: 100px on screen, 30mm in print. Below that, use the icon.
- "Support Services" is not part of the logo. Use it in text: website title, invoices, listings.

## Status
These are production-ready concept files drawn on a geometric grid. Before large print runs (signage, vehicles), have a designer do an optical refinement pass and supply print colour values (CMYK/Pantone).
